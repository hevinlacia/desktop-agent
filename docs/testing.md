# 测试与验证

## 三层验证

| 层 | 命令 | 覆盖什么 | 需要 |
|---|---|---|---|
| 类型检查 | `just typecheck` | node 侧与 web 侧两个 tsconfig；契约改了没同步会在这里报 | — |
| 单元测试 | `just test` | 纯函数：事件归一化、配置合并与尺寸夹取、快捷键写法规整、命令行参数解析、外链协议判断、旧版 KWin 脚本检测 | — |
| 端到端自检 | `just smoke` | 真实启动应用走完整条链路 | 本机 pi 配好可用模型 |

交付前 `just check` 跑前两层加构建。改了契约、Agent 子进程、窗口形态、打包配置之后要跑一次 `just smoke`。

## 端到端自检做了什么

`just smoke`（即 `DESKTOP_AGENT_SELFTEST=tmp/selftest bun run start`）启动真实的应用，依次断言：

1. **Agent 就绪**：能取到会话状态（含当前模型）和会话列表。
2. **完整形态**：侧边栏展开（224px）、输入框存在、会话列表渲染出行数与 Agent 报告的一致。
3. **悬浮窗形态**：宿主切换后渲染进程跟着换布局（侧边栏 40px）、窗口高度明显变小。
4. **界面提问**：点「新建会话」→ 在输入框打字 → 回车 → Agent 开跑并收尾 → 回复渲染到消息区。
5. **外部提问**：再启动一个 `desktop-agent ask "<问题>"` 进程 → 经单实例通道进入同一个窗口 → 同样收到回复。
6. **链接安全**：在页面里点一个链接 → 交给了系统浏览器（自检里只记录不真开）→ 没有开新窗口 → 应用窗口没有跳走。

退出码即结果：`0` 通过，`1` 断言失败，`2` 超时。截图（`1-full.png`、`2-compact.png`、`3-reply.png`）和 `result.json` 写在输出目录。`result.json` 里记录了模型名、两轮对话的耗时与事件计数，可以直接贴进问题单。

几点设计上的取舍：

- **走界面路径，不走捷径**。渲染进程按 `sessionId` 丢弃迟到事件，绕过它直接调主进程的 `newSession()` 会让后续事件全被丢掉，测出来的也不是用户实际走的那条路。
- **离屏渲染**。窗口被别的窗口盖住时 KWin 不再发帧回调，Chromium 会停在旧画面上，`capturePage` 拿到的是旧帧。自检模式改用离屏渲染，从 `paint` 事件取最新帧，不依赖窗口在最前。
- **会话不落盘**。自检模式下用内存会话，测试提问不会出现在 pi 的会话列表里。代价是持久化路径只在日常使用中覆盖。
- **要花两次模型调用**。各一句话，通常 4 秒左右。

对打包产物跑自检（验证的是安装包里的依赖和资源路径，而不是源码目录）——动过依赖或打包配置之后要跑：

```bash
just package
DESKTOP_AGENT_SELFTEST=/tmp/da-selftest release/linux-unpacked/desktop-agent
```

`release/linux-unpacked` 就是 pacman 包解出来的内容。偶尔打 AppImage 的话，加 `--appimage-extract-and-run` 运行（Arch 上没装 `fuse2` 时必须加）。

## 自检覆盖不到的，要手工看

这些依赖真实合成器、真实键盘或用户授权，改了相关代码后请过一遍：

- [ ] 四角是真透明圆角，悬浮窗和对话窗口都是（**开着 DevTools 时窗口不透明**，先关掉）
- [ ] 标题栏能拖动；窗口能手动缩放
- [ ] 回复里的链接点击后用系统浏览器打开，应用窗口自己不跳走
- [ ] 输入法：中文候选、翻页、回车选词不会把半截内容发出去（输入框按 `isComposing` 判断）
- [ ] 全局快捷键：首次弹出系统的「全局快捷键权限请求」，授权后 `Meta+Space` 能唤起/收起
- [ ] 托盘菜单：两种形态、新建会话、打开配置文件、退出
- [ ] 关窗只是隐藏；托盘「退出」能退干净（`ps` 里没有残留）
- [ ] `systemctl --user` 或注销时应用不拖住退出流程
- [ ] 悬浮窗失焦自动收起，完整窗口不会
- [ ] 会话列表里切换会话，消息区跟着换
- [ ] 设置里改快捷键、尺寸、工作目录后立即生效；填一个非法快捷键会回退并提示

## 排查手段

- 从终端启动看日志：`just start`。关注 `[shortcut]`、`[agent]`、`[quit]` 三类前缀。
- 渲染进程：开发模式按 F12 开 DevTools。
- 快捷键冲突：`grep -n 'Meta+Space' ~/.config/kglobalshortcutsrc`。
- 确认应用身份：`ls /usr/share/applications/desktop-agent.desktop`（或 `~/.local/share/applications/`）。没有这个文件，portal 就认不出应用。
